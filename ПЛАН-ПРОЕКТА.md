# План проекта: Django Project Store (домашние задания)

Пошаговый план разработки с декомпозицией задач.

---

## Описание проекта

Учебный Django-проект для выполнения домашних заданий: настройка проекта, приложение catalog, шаблоны (главная и контакты), контроллеры и форма обратной связи.

## Цели проекта

1. Настроить проект Django (директория, venv, GitFlow, README, .gitignore).
2. Создать и подключить приложение catalog с маршрутизацией.
3. Подготовить HTML-шаблоны главной и контактов со стилизацией Bootstrap.
4. Реализовать контроллеры для главной и контактов, настроить маршруты.
5. (Дополнительно) Реализовать форму обратной связи на странице контактов с сообщением об успешной отправке.

### Итерация 1: Настройка проекта (Задание 1)

#### Понятные шаги

1. Создать директорию проекта — выполнено (django-project-store).
2. Настроить виртуальное окружение — выполнено (.venv, Poetry/pip).
3. Инициализировать Django-проект внутри директории — выполнено (config/, manage.py).

**Результат:** Задание 1 выполнено.

---

### Итерация 2: Создание и настройка приложения catalog (Задание 2)

#### Понятные шаги

1. Создать приложение catalog: `python manage.py startapp catalog`.
2. Зарегистрировать приложение в `config/settings.py`: добавить `"catalog"` в `INSTALLED_APPS`.
3. Создать `catalog/urls.py` с пустым `urlpatterns` (и при необходимости `app_name = 'catalog'`).
4. В `config/urls.py` подключить маршруты приложения: `path('', include('catalog.urls'))` (или с префиксом `catalog/` по заданию).

**Результат:** Приложение catalog создано, зарегистрировано, маршрутизация настроена.

---

### Итерация 3: Шаблоны (Задание 3)

#### Понятные шаги

1. Создать структуру шаблонов: `catalog/templates/catalog/` (или общую `templates/` в корне с подпапкой `catalog`).
2. Создать `home.html`: разметка главной страницы, подключение Bootstrap (CDN или локально из static).
3. Создать `contacts.html`: разметка страницы контактов, подключение Bootstrap.
4. В `config/settings.py` при необходимости задать `DIRS` в `TEMPLATES` для общих шаблонов (если шаблоны в корне).

**Результат:** Два шаблона готовы, стилизация через Bootstrap.

---

### Итерация 4: Контроллеры и маршрутизация (Задание 4)

#### Понятные шаги

1. В `catalog/views.py` создать контроллер для главной: функция `home(request)`, возвращающая `render(request, 'catalog/home.html')`.
2. В `catalog/views.py` создать контроллер для контактов: функция `contacts(request)`, возвращающая `render(request, 'catalog/contacts.html')`.
3. В `catalog/urls.py` добавить маршруты: главная (например `''` или `'home/'`), контакты (`'contacts/'`).
4. Убедиться, что в `config/urls.py` подключены `catalog.urls` с нужным префиксом.

**Результат:** Главная и контакты открываются по заданным URL.

---

### Итерация 5: Форма обратной связи (дополнительное задание)

#### Понятные шаги

1. В шаблоне `contacts.html` добавить форму: поля (например имя, email, сообщение), `method="post"`, `{% csrf_token %}`.
2. В контроллере `contacts` обрабатывать `request.method == 'POST'`: читать данные из `request.POST`, при успехе показывать сообщение (отдельная страница или тот же шаблон с флагом/сообщением).
3. После отправки отображать сообщение об успешной отправке (например через `messages` или переменную контекста `success=True` и блок в шаблоне).

**Результат:** Форма обратной связи на странице контактов с отображением успешной отправки.
