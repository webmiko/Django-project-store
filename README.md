# Django Project Store

Проект на Django с настроенным виртуальным окружением Poetry и инструментами разработки.

## Установка и настройка

### Активация виртуального окружения

```bash
source .venv/bin/activate
```

Или если используете Poetry:

```bash
poetry shell
```

### Установка зависимостей

Все зависимости уже установлены. Если нужно переустановить:

```bash
pip install -r requirements.txt
```

Или через Poetry:

```bash
poetry install
```

### Переменные окружения (.env)

Настройки (секретный ключ, БД, DEBUG) берутся из файла `.env` в корне проекта.

- **Уже есть `.env`** — проект готов к запуску (локальная разработка на SQLite).
- **Нет `.env`** (например, после клонирования) — скопируйте шаблон и при необходимости отредактируйте:
  ```bash
  cp .env.example .env
  ```
  В `.env.example` описаны все переменные. Для разработки достаточно оставить `DB_NAME` пустым (будет использоваться SQLite). Файл `.env` в репозиторий не попадает.

## Установленные инструменты

### Основные зависимости
- **Django** 6.0.1 - веб-фреймворк
- **psycopg2-binary** - драйвер для PostgreSQL
- **python-dotenv** - работа с переменными окружения

### Инструменты разработки
- **black** - форматирование кода
- **flake8** - линтер для проверки стиля кода
- **pylint** - статический анализатор кода
- **mypy** - проверка типов
- **isort** - сортировка импортов
- **pytest** - фреймворк для тестирования
- **pytest-django** - плагин pytest для Django
- **django-debug-toolbar** - инструмент отладки для Django
- **ipython** - улучшенная интерактивная оболочка Python

## Использование инструментов

### Форматирование кода
```bash
black .
isort .
```

### Проверка кода
```bash
flake8 .
pylint .
mypy .
```

### Запуск тестов
```bash
pytest
```

## Запуск проекта

```bash
python manage.py runserver
```

- Главная страница: http://127.0.0.1:8000/
- Контакты (с формой обратной связи): http://127.0.0.1:8000/contacts/
- Админ-панель: http://127.0.0.1:8000/admin/

## Приложение catalog

В проекте настроено приложение **catalog** с:

- Главной страницей (шаблон `home.html`, Bootstrap)
- Страницей контактов (шаблон `contacts.html`) и формой обратной связи с сообщением об успешной отправке

Подробный план разработки и декомпозиция задач — в файле `ПЛАН-ПРОЕКТА.md`.

## Создание Django проекта

Если нужно создать новый Django проект:

```bash
django-admin startproject projectname .
```

Или создать приложение:

```bash
python manage.py startapp appname
```

## Правила коммитов

Все коммиты в этом проекте делаются **на русском языке**.

### Формат коммитов:
- **Кратко и понятно** - описание до 50 символов в первой строке
- **На русском языке** - все сообщения коммитов на русском
- **Понятно, но не длинно** - избегайте излишней детализации

### Примеры хороших коммитов:
```
Добавить модель Product для каталога товаров
Исправить баг с валидацией email в форме регистрации
Обновить зависимости в requirements.txt
Добавить тесты для API эндпоинтов
Рефакторинг: вынести логику в отдельный сервис
```

### Примеры плохих коммитов:
```
fix
обновления
Исправление бага который был найден вчера вечером когда я тестировал форму регистрации и заметил что валидация email не работает правильно
```

Шаблон коммита настроен в `.gitmessage` и будет автоматически использоваться при создании коммитов.
